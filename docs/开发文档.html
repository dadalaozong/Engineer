职称申报自动化系统

广西住建行业职称申报 · 本地桌面工具 · 开发文档 v2.0（2026-06）

本系统面向职称申报中介人员，实现「建档 → 归档 → 查漏 → 一键填报」全流程自动化。 申报对象为广西壮族自治区工程系列住房城乡建设行业职称（技术员 / 助理工程师 / 工程师 / 高级工程师 / 正高级工程师）。 目标网站：https://my.gxrczc.com/Login

项目背景与目标

痛点

当前问题系统解决方式
每人材料散乱，靠手动整理文件夹新建项目时自动生成标准目录结构
容易遗漏材料，提交前才发现完整性检查模块，按职称级别校验
网上填报重复劳动，同类字段反复输入Playwright 自动登录、自动填表
申报人信息分散在微信/Excel本地 SQLite 数据库统一管理

核心目标

📁

标准化建档

新建申报项目，根据职称级别自动生成本地文件夹树，每个材料类型有对应的存放位置。

✅

完整性检查

按职称级别的必要材料清单，逐项检查文件夹内是否有对应文件，缺少时高亮提示。

🤖

自动化填报

读取数据库中的申报人信息，启动 Playwright 浏览器，自动登录并填写各表单页面。

🗂️

多人批量管理

支持同时管理多个申报人，每人独立项目，状态跟踪（建档 / 材料齐全 / 已提交）。

两种"账号"不要混淆：
① 系统操作者（你）：直接打开桌面程序，无需登录，无账号概念。
② 申报人账号（客户在 gxrczc.com 上的账号）：存在数据库里，供自动登录时调用。

M3 · OCR 证件识别

系统使用 PaddleOCR（百度开源，本地运行，不联网）自动识别申报人证件图片，提取关键字段，减少手工录入工作量。

⚠️ OCR 为辅助手段，识别结果须人工核对确认后才写入数据库。置信度 < 85% 的字段高亮为黄色，提示重点检查。

支持识别的证件类型

证件类型可提取字段备注
🪪 身份证（正面） 姓名、性别、民族、出生日期、身份证号、住址 PaddleOCR 内置身份证模型，准确率 >95%
🎓 毕业证书 姓名、院校、专业、学历层次、毕业年份、证书编号 通用文字识别，关键字段用正则匹配提取
📜 职称证书 姓名、职称名称、专业、级别、发证年份、发证机构 通用文字识别
🏢 学位证书 姓名、学位类型、授予院校、授予年份 通用文字识别

from paddleocr import PaddleOCR
import re

ocr = PaddleOCR(use_angle_cls=True, lang="ch", show_log=False)

def read_id_card(image_path: str) -> dict:
    """识别身份证正面，返回结构化字段 + 置信度"""
    result = ocr.ocr(image_path, cls=True)
    texts = [(line[1][0], line[1][1]) for line in result[0]]  # (text, confidence)

    fields = {}
    for text, conf in texts:
        if re.search(r"姓\s*名", text):
            next_text = _next_value(texts, text)
            fields["name"] = {"value": next_text, "conf": conf}
        elif re.search(r"公民身份号码|身份证号", text):
            id_match = re.search(r"\d{17}[\dX]", text)
            if id_match:
                fields["id_number"] = {"value": id_match.group(), "conf": conf}
        elif re.search(r"出生", text):
            date_match = re.search(r"(\d{4})年(\d{1,2})月(\d{1,2})日", text)
            if date_match:
                fields["birth_date"] = {"value": f"{date_match.group(1)}-{date_match.group(2):0>2}-{date_match.group(3):0>2}", "conf": conf}
        elif re.search(r"民族", text):
            fields["ethnicity"] = {"value": text.replace("民族", "").strip(), "conf": conf}
        elif re.search(r"性别", text):
            gender = "男" if "男" in text else "女" if "女" in text else ""
            fields["gender"] = {"value": gender, "conf": conf}
    return fields

def read_diploma(image_path: str) -> dict:
    """识别毕业证，返回姓名、院校、专业、学历、年份"""
    result = ocr.ocr(image_path, cls=True)
    full_text = " ".join([line[1][0] for line in result[0]])
    fields = {}

    # 院校
    school = re.search(r"([一-龥]+(?:大学|学院|学校))", full_text)
    if school:
        fields["school"] = {"value": school.group(1), "conf": 0.9}

    # 学历层次
    for edu in ["博士研究生", "硕士研究生", "本科", "专科", "中专"]:
        if edu in full_text:
            fields["education"] = {"value": edu.replace("研究生",""), "conf": 0.95}
            break

    # 毕业年份
    year = re.search(r"(\d{4})\s*年", full_text)
    if year:
        fields["graduation_year"] = {"value": year.group(1), "conf": 0.9}

    return fields

置信度颜色规则

置信度界面显示含义

85%～90%🔵 蓝色识别较好，建议核对

M6 · 自动填报

账号密码加密存储

申报人在 gxrczc.com 的登录密码属于敏感信息，不能明文存储在 SQLite 数据库中。 使用 Python cryptography 库的 Fernet 对称加密方案，加密密钥存储在系统本地，与数据库文件分开保存。

安全原则：密钥文件（~/.zcsbxt/secret.key）与数据库文件（~/.zcsbxt/data.db）分开存放。 即使数据库被复制走，没有密钥文件也无法解密密码。

加密方案代码（core/crypto.py）

from cryptography.fernet import Fernet
from pathlib import Path

KEY_PATH = Path.home() / ".zcsbxt" / "secret.key"

def get_or_create_key() -> bytes:
    """获取或初始化加密密钥（首次运行自动生成）"""
    if KEY_PATH.exists():
        return KEY_PATH.read_bytes()
    KEY_PATH.parent.mkdir(parents=True, exist_ok=True)
    key = Fernet.generate_key()
    KEY_PATH.write_bytes(key)
    return key

_fernet = Fernet(get_or_create_key())

def encrypt_password(plain_text: str) -> str:
    """加密密码，返回可存入数据库的字符串"""
    return _fernet.encrypt(plain_text.encode()).decode()

def decrypt_password(cipher_text: str) -> str:
    """解密密码，返回明文（仅在登录时调用）"""
    return _fernet.decrypt(cipher_text.encode()).decode()

使用方式

规模判断核心代码（core/scale_engine.py）

"""
工程规模判断引擎
输入：专业类型 + 项目各指标数值
输出：'大型' | '中型' | '小型'
规则：满足任一大型指标 → 大型；否则满足任一中型指标 → 中型；否则 → 小型
"""

SCALE_RULES = {
    "房屋建筑": [
        # (指标名, 单位, 大型阈值_min, 中型阈值_min)
        ("层数",         "层",   25,      5),
        ("高度",         "米",   100,     15),
        ("单跨跨度",     "米",   30,      15),
        ("单体建筑面积", "㎡",   30000,   3000),
        ("总建筑面积",   "㎡",   100000,  3000),
        ("合同额",       "万元", 3000,    300),
    ],
    "市政公用": [
        ("道路长度",       "km",   5,    2),
        ("桥梁单跨",       "米",   40,   20),
        ("隧道内径",       "米",   5,    3),
        ("供排水管径",     "mm",   1500, 800),
        ("日处理量_水",    "万吨", 5,    3),
        ("日处理量_垃圾",  "吨",   800,  400),
        ("合同额",         "万元", 3000, 1000),
    ],
    "装饰装修": [
        ("合同额",   "万元", 1000, 100),
        ("幕墙高度", "米",   60,   None),  # None表示无中型
        ("幕墙面积", "㎡",   6000, None),
    ],
    "机电安装": [
        ("合同额",     "万元", 1500, 200),
        ("空调面积",   "万㎡", 2,    1),
        ("智能化合同", "万元", 500,  200),
        ("管道合同",   "万元", 1000, 300),
    ],
    "公路工程": [
        ("高速公路", "—",   1,    None),   # 1=是高速，直接大型
        ("桥梁单跨", "米",  50,   13),
        ("隧道长度", "米",  1000, None),
        ("合同额",   "万元", 3000, 500),
    ],
}

def judge_scale(specialty: str, indicators: dict) -> tuple[str, str]:
    """
    返回 (规模等级, 判断依据说明)
    indicators: {'层数': 28, '合同额': 5000, ...}
    """
    rules = SCALE_RULES.get(specialty, [])
    hit_large, hit_medium = [], []

    for name, unit, large_min, medium_min in rules:
        val = indicators.get(name)
        if val is None:
            continue
        if val >= large_min:
            hit_large.append(f"{name}={val}{unit}（≥{large_min}）")
        elif medium_min and val >= medium_min:
            hit_medium.append(f"{name}={val}{unit}（≥{medium_min}）")

    if hit_large:
        return "大型", "满足：" + "、".join(hit_large)
    if hit_medium:
        return "中型", "满足：" + "、".join(hit_medium)
    return "小型", "所有指标均低于中型门槛"

完整性检查中的业绩规模校验（core/checker.py）

"""
中级工程师 业绩要求校验（以设计/施工/监理/项目管理为例）
"""
def check_achievements_mid(achievements: list[dict]) -> dict:
    large = [a for a in achievements if a['scale'] == '大型']
    medium = [a for a in achievements if a['scale'] == '中型']
    small  = [a for a in achievements if a['scale'] == '小型']

    # 规则：2中型，或1中+2小，或4小（其中1-12条至少1条）
    combos = [
        (len(medium) >= 2,                    "已有中型项目 2 项 ✓"),
        (len(medium) >= 1 and len(small) >= 2, "已有中型 1 项 + 小型 2 项 ✓"),
        (len(small) >= 4,                      "已有小型项目 4 项 ✓"),
    ]
    passed = any(ok for ok, _ in combos)
    reason = next((msg for ok, msg in combos if ok), None)

    if not passed:
        gap = f"当前：大型{len(large)}项、中型{len(medium)}项、小型{len(small)}项。" \
              f"需补充至少：{_mid_gap(medium, small)}"
        return {"pass": False, "msg": gap}
    return {"pass": True, "msg": reason}


def check_achievements_high(achievements: list[dict]) -> dict:
    """
    高级工程师 业绩要求（设计/施工/监理类）：
    2大型，或 1大+2中，或 4中型
    """
    large  = [a for a in achievements if a['scale'] == '大型']
    medium = [a for a in achievements if a['scale'] == '中型']

    combos = [
        (len(large) >= 2,                      "已有大型项目 2 项 ✓"),
        (len(large) >= 1 and len(medium) >= 2, "已有大型 1 项 + 中型 2 项 ✓"),
        (len(medium) >= 4,                     "已有中型项目 4 项 ✓"),
    ]
    passed = any(ok for ok, _ in combos)
    reason = next((msg for ok, msg in combos if ok), None)

    if not passed:
        gap = f"当前：大型{len(large)}项、中型{len(medium)}项。" \
              f"需补充：{_high_gap(large, medium)}"
        return {"pass": False, "msg": gap}
    return {"pass": True, "msg": reason}

填写任一指标数值 实时调用 judge_scale()，在表单右侧显示「🟢 大型」/「🟡 中型」/「🔴 小型」标签
保存业绩条目 将规模结果（scale 字段）一并存入数据库 achievements 表
点击「检查材料完整性」 读取所有业绩的 scale 字段，按职称级别调用对应 checker 函数，输出是否满足条件及缺口数量
⚠️ 注意：不同业绩类型（设计类、施工/监理类、造价类、咨询检测类）的规模要求数量不同。 系统需记录每条业绩的工作类型，分组统计后分别校验：
• 设计/施工/监理/项目管理：中级需 2中型以上；高级需 2大型 或 1大+2中 或 4中
• 咨询/检测/质量监督：中级需 5大中型(含1大型)；高级需 10大中型(含5大型)
• 工程造价/招投标：中级需 4中型以上 或 6小型；高级需 6大中型(含2大型) 或 10小型

AI 辅助写作 · DeepSeek 接入设计

在职称申报中，代表作说明书、工程业绩描述、专业技术工作总结是文字量最大、最耗时的环节。 系统接入 DeepSeek API，根据已录入的结构化数据自动起草，供人工审核后使用。

接口兼容性：DeepSeek API 完全兼容 OpenAI 格式，只需替换 base_url 和 api_key， 无需额外 SDK，使用 openai Python 包即可调用。 推荐模型：deepseek-chat（价格低、中文效果好）。

适用场景一览

功能触发时机输入数据输出
📄 代表作说明书 业绩录入完成后，点击「AI起草」 工程名称、规模、本人职务、工作内容、获奖情况 ~800字说明书正文，Word格式
📝 工程业绩描述 单条业绩录入后，点击「AI补全描述」 项目基本信息 + 合同额 + 本人职责 100~150字业绩简述，用于填报表格
📋 专业技术工作总结 完整性检查通过后，点击「AI生成总结」 全部业绩列表 + 获奖 + 论文 + 工作年限 ~1500字个人技术工作总结
🏆 获奖描述补全 获奖信息录入后，可选触发 获奖名称、级别、颁奖机构、年份、本人角色 50字获奖贡献说明

模块设计

# ai_writer.py from openai import OpenAI from pathlib import Path import json class AIWriter: def __init__(self, api_key: str): self.client = OpenAI( api_key=api_key, base_url="https://api.deepseek.com" ) self.model = "deepseek-chat" def _call(self, prompt: str) -> str: resp = self.client.chat.completions.create( model=self.model, messages=[ {"role": "system", "content": "你是一名专业的建筑工程职称申报材料撰写专家，熟悉广西住建行业职称评审条件。"}, {"role": "user", "content": prompt} ], temperature=0.7, max_tokens=2000, ) return resp.choices[0].message.content def gen_representative_work(self, project: dict) -> str: """生成代表作说明书""" prompt = PROMPT_REPRESENTATIVE.format(**project) return self._call(prompt) def gen_achievement_desc(self, achievement: dict) -> str: """生成单条业绩描述（用于网上填报）""" prompt = PROMPT_ACHIEVEMENT.format(**achievement) return self._call(prompt) def gen_work_summary(self, applicant: dict, achievements: list, awards: list, papers: list) -> str: """生成专业技术工作总结""" prompt = PROMPT_SUMMARY.format( name=applicant["name"], title_level=applicant["title_level"], years=applicant["work_years"], achievements=json.dumps(achievements, ensure_ascii=False, indent=2), awards=json.dumps(awards, ensure_ascii=False, indent=2), papers=json.dumps(papers, ensure_ascii=False, indent=2), ) return self._call(prompt) def save_to_docx(self, content: str, output_path: Path): """将AI输出写入Word文档（需要python-docx）""" from docx import Document doc = Document() for line in content.split("\n"): doc.add_paragraph(line) doc.save(output_path)

# config.py import json, os from pathlib import Path CONFIG_PATH = Path.home() / ".zcsbxt" / "config.json" def load_config() -> dict: if CONFIG_PATH.exists(): return json.loads(CONFIG_PATH.read_text(encoding="utf-8")) return {} def save_config(cfg: dict): CONFIG_PATH.parent.mkdir(parents=True, exist_ok=True) CONFIG_PATH.write_text(json.dumps(cfg, ensure_ascii=False, indent=2), encoding="utf-8") # 使用示例 cfg = load_config() writer = AIWriter(api_key=cfg.get("deepseek_api_key", ""))

AI Prompt 模板

① 代表作说明书

PROMPT_REPRESENTATIVE = """ 请根据以下工程项目信息，撰写一份职称评审代表作说明书，字数约800字。 【项目基本信息】 工程名称：{name} 建设地点：{location} 工程类型：{project_type} 工程规模：{scale}（建筑面积{area}㎡ / {floors}层 / 合同额{contract}万元） 建设单位：{owner} 施工单位：{contractor} 本人职务：{role} 在职时间：{start_date} 至 {end_date} 【获奖情况】 {awards} 【撰写要求】 1. 开头说明工程概况和重要性 2. 重点描述本人承担的技术职责和解决的关键技术问题 3. 说明工程技术创新点或难点突破 4. 结合获奖情况说明工程质量和社会效益 5. 语言专业、客观、符合政府机关公文风格 6. 不要使用夸张词汇，数据必须与输入信息一致 """

② 单条业绩描述（网上填报用）

PROMPT_ACHIEVEMENT = """ 请根据以下信息，撰写一段工程业绩简介，用于职称申报系统网上填报，字数100~150字。 工程名称：{name} 工程类型：{project_type} 建筑面积：{area}㎡ 层数/高度：{floors}层/{height}米 合同金额：{contract}万元 本人职务：{role} 主要工作：{work_content} 要求：语言简洁，突出本人贡献，数据准确，一段话，无标题。 """

③ 专业技术工作总结

PROMPT_SUMMARY = """ 请根据以下申报人信息，撰写一份专业技术工作总结，字数约1500字，格式为分段正文（无需编号标题）。 申报人：{name} 申报职称：{title_level} 从事专业年限：{years}年 【工程业绩】 {achievements} 【获奖情况】 {awards} 【论文著作】 {papers} 撰写要求： 1. 概述从业经历和技术成长轨迹 2. 按时间或项目类型分段介绍主要业绩 3. 突出技术能力、解决复杂问题的能力 4. 提及获奖和论文体现学术贡献 5. 结尾总结技术水平达到{title_level}评审条件 6. 符合广西住建行业职称评审语言风格 """
注意事项： AI 生成内容为草稿，申报人必须审核确认所有数据与实际情况一致后方可使用。 系统在 AI 生成界面顶部显示醒目提示：「以下内容由 AI 辅助生成，请仔细核对所有数据后再使用」。

运行说明

安装依赖

pip install PyQt5 playwright openpyxl Pillow pymupdf
python -m playwright install chromium

启动程序

python main.py

首次使用步骤

  1. 在「设置」中配置申报文件根目录（如 D:\职称申报\）
  2. 点击「新建项目」，录入申报人基本信息
  3. 选择职称级别，系统自动在根目录下创建该申报人的文件夹
  4. 把身份证、毕业证等材料放入对应文件夹
  5. 录入工程业绩、获奖信息等结构化数据
  6. 点击「检查材料」，确认全部通过
  7. 点击「启动网上填报」，确认后自动提交
