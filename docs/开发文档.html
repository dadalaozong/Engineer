职称申报自动化系统

广西住建行业职称申报 · 本地桌面工具 · 开发文档 v1.0（2026-06）

本系统面向职称申报中介人员，实现「建档 → 归档 → 查漏 → 一键填报」全流程自动化。 申报对象为广西壮族自治区工程系列住房城乡建设行业职称（技术员 / 助理工程师 / 工程师 / 高级工程师 / 正高级工程师）。 目标网站：https://my.gxrczc.com/Login

项目背景与目标

痛点

当前问题系统解决方式
每人材料散乱，靠手动整理文件夹新建项目时自动生成标准目录结构
容易遗漏材料，提交前才发现完整性检查模块，按职称级别校验
网上填报重复劳动，同类字段反复输入Playwright 自动登录、自动填表
申报人信息分散在微信/Excel本地 SQLite 数据库统一管理

核心目标

📁

标准化建档

新建申报项目，根据职称级别自动生成本地文件夹树，每个材料类型有对应的存放位置。

✅

完整性检查

按职称级别的必要材料清单，逐项检查文件夹内是否有对应文件，缺少时高亮提示。

🤖

自动化填报

读取数据库中的申报人信息，启动 Playwright 浏览器，自动登录并填写各表单页面。

🗂️

多人批量管理

支持同时管理多个申报人，每人独立项目，状态跟踪（建档 / 材料齐全 / 已提交）。

M3 · 材料管理

在 GUI 界面中展示当前申报项目的文件夹树，支持以下操作：

M4 · 完整性检查

点击「检查材料完整性」，系统逐条扫描文件夹并输出报告。

检查逻辑

检查项规则不通过时
01_基本材料目录下每个必要文件名模式至少有1个文件🔴 标红，列出缺少项
02_工程业绩子目录数量 ≥ 该职称要求的最少业绩数量🔴 提示还需 N 项业绩
每项业绩子目录目录内至少有1个 PDF 文件🟡 提示材料不完整
03_获奖证书高级/正高级：目录下至少1个文件🔴 缺失
04_论文著作高级：≥1篇；正高级：≥1篇含核心期刊标注🔴 缺失
06_代表作高级/正高级：包含说明文件 + 证明材料🔴 缺失
数据库录入工程业绩表单字段是否已填写完整🟡 提示待录入

M5 · 自动填报

点击「启动网上填报」后，系统自动打开浏览器，完成从登录到提交的全流程。

⚠️ 在正式自动提交前，系统会弹出「确认提交」对话框，展示所有将填写的内容，用户手动点击确认才会执行提交，防止误操作。

自动填报步骤

① 从数据库读取申报人账号密码
↓
② Playwright 打开 gxrczc.com 登录页，自动填写账号密码并登录
↓
③ 导航到「个人申报」→「新建申报」
↓
④ 填写基本信息页（姓名、身份证号、学历、工作单位…）
↓
⑤ 逐条填写工程业绩（循环插入每条记录）
↓
⑥ 填写获奖信息、论文信息
↓
⑦ 上传材料文件（从本地文件夹读取 PDF 上传）
↓
⑧ 弹窗确认 → 用户手动确认 → 提交

材料清单规范

以下是 core/title_rules.py 中配置的各级职称材料规则（系统完整性检查的依据）。

必填材料（所有职称通用）

  • 身份证正反面（文件名含「身份证」）
  • 毕业证书（文件名含「毕业证」）
  • 社保缴纳证明（文件名含「社保」）
  • 继续教育完成证明（文件名含「继续教育」）
  • 近3年年度考核证明（文件名含「考核」）
  • 工程业绩 ≥ 1 项（根据职称级别具体要求不同）

工程师 额外要求

  • 现有职称证书（助理工程师证书）
  • 工程业绩 ≥ 2 项（含1至12条中至少1条）
  • 论文/著作（不强制，有业绩2项可免）
  • 专利证书

高级工程师 额外要求

  • 现有职称证书（工程师证书）
  • 工程业绩：具备1-17中1条 + 18-23中1条，或1-17中2条 + 第24条
  • 获奖证书 至少1项（1-3条）
  • 论文/著作 至少1篇（18-24条之一）
  • 代表作（指定1项标志性成果）
  • 专利证书
  • 科研项目证明

正高级工程师 额外要求

  • 现有职称证书（高级工程师证书）
  • 获奖类条件（1-6条）至少1项
  • 工程业绩类条件（7-15条）至少1项
  • 论文著作类条件（16-19条）至少1项（含核心期刊）
  • 代表作（指定1项标志性成果）

登录流程

# automation/browser.py  示意
from playwright.async_api import async_playwright

async def login(account: str, password: str):
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=False)  # 有界面，便于观察
        page = await browser.new_page()
        await page.goto("https://my.gxrczc.com/Login")

        # 填写账号密码
        await page.fill('input[name="username"]', account)
        await page.fill('input[name="password"]', password)
        await page.click('button[type="submit"]')

        # 等待跳转成功
        await page.wait_for_url("**/index**", timeout=10000)
        return page  # 返回已登录的 page 对象
✅ 登录页无验证码，直接账号密码提交即可。首次使用时先手动登录确认账号密码正确，再录入系统。

# automation/form_filler.py  示意
async def fill_basic_info(page, applicant):
    await page.fill('#name',    applicant['name'])
    await page.fill('#id_card', applicant['id_number'])
    await page.select_option('#gender',    applicant['gender'])
    await page.select_option('#education', applicant['education'])
    await page.fill('#work_unit', applicant['work_unit'])
    await page.click('#next-btn')   # 下一步

async def fill_achievements(page, achievements):
    for ach in achievements:
        await page.click('#add-achievement-btn')   # 点击「新增业绩」
        await page.fill('.ach-name',    ach['project_name'])
        await page.select_option('.ach-type',  ach['project_type'])
        await page.select_option('.ach-scale', ach['project_scale'])
        await page.select_option('.ach-role',  ach['my_role'])
        await page.fill('.ach-content', ach['work_content'])
        await page.click('.ach-save-btn')
    await page.click('#next-btn')

async def upload_file(page, selector, file_path):

规模判断核心代码（core/scale_engine.py）

"""
工程规模判断引擎
输入：专业类型 + 项目各指标数值
输出：'大型' | '中型' | '小型'
规则：满足任一大型指标 → 大型；否则满足任一中型指标 → 中型；否则 → 小型
"""

SCALE_RULES = {
    "房屋建筑": [
        # (指标名, 单位, 大型阈值_min, 中型阈值_min)
        ("层数",         "层",   25,      5),
        ("高度",         "米",   100,     15),
        ("单跨跨度",     "米",   30,      15),
        ("单体建筑面积", "㎡",   30000,   3000),
        ("总建筑面积",   "㎡",   100000,  3000),
        ("合同额",       "万元", 3000,    300),
    ],
    "市政公用": [
        ("道路长度",       "km",   5,    2),
        ("桥梁单跨",       "米",   40,   20),
        ("隧道内径",       "米",   5,    3),
        ("供排水管径",     "mm",   1500, 800),
        ("日处理量_水",    "万吨", 5,    3),
        ("日处理量_垃圾",  "吨",   800,  400),
        ("合同额",         "万元", 3000, 1000),
    ],
    "装饰装修": [
        ("合同额",   "万元", 1000, 100),
        ("幕墙高度", "米",   60,   None),  # None表示无中型
        ("幕墙面积", "㎡",   6000, None),
    ],
    "机电安装": [
        ("合同额",     "万元", 1500, 200),
        ("空调面积",   "万㎡", 2,    1),
        ("智能化合同", "万元", 500,  200),
        ("管道合同",   "万元", 1000, 300),
    ],
    "公路工程": [
        ("高速公路", "—",   1,    None),   # 1=是高速，直接大型
        ("桥梁单跨", "米",  50,   13),
        ("隧道长度", "米",  1000, None),
        ("合同额",   "万元", 3000, 500),
    ],
}

def judge_scale(specialty: str, indicators: dict) -> tuple[str, str]:
    """
    返回 (规模等级, 判断依据说明)
    indicators: {'层数': 28, '合同额': 5000, ...}
    """
    rules = SCALE_RULES.get(specialty, [])
    hit_large, hit_medium = [], []

    for name, unit, large_min, medium_min in rules:
        val = indicators.get(name)
        if val is None:
            continue
        if val >= large_min:
            hit_large.append(f"{name}={val}{unit}（≥{large_min}）")
        elif medium_min and val >= medium_min:
            hit_medium.append(f"{name}={val}{unit}（≥{medium_min}）")

    if hit_large:
        return "大型", "满足：" + "、".join(hit_large)
    if hit_medium:
        return "中型", "满足：" + "、".join(hit_medium)
    return "小型", "所有指标均低于中型门槛"

完整性检查中的业绩规模校验（core/checker.py）

"""
中级工程师 业绩要求校验（以设计/施工/监理/项目管理为例）
"""
def check_achievements_mid(achievements: list[dict]) -> dict:
    large = [a for a in achievements if a['scale'] == '大型']
    medium = [a for a in achievements if a['scale'] == '中型']
    small  = [a for a in achievements if a['scale'] == '小型']

    # 规则：2中型，或1中+2小，或4小（其中1-12条至少1条）
    combos = [
        (len(medium) >= 2,                    "已有中型项目 2 项 ✓"),
        (len(medium) >= 1 and len(small) >= 2, "已有中型 1 项 + 小型 2 项 ✓"),
        (len(small) >= 4,                      "已有小型项目 4 项 ✓"),
    ]
    passed = any(ok for ok, _ in combos)
    reason = next((msg for ok, msg in combos if ok), None)

    if not passed:
        gap = f"当前：大型{len(large)}项、中型{len(medium)}项、小型{len(small)}项。" \
              f"需补充至少：{_mid_gap(medium, small)}"
        return {"pass": False, "msg": gap}
    return {"pass": True, "msg": reason}


def check_achievements_high(achievements: list[dict]) -> dict:
    """
    高级工程师 业绩要求（设计/施工/监理类）：
    2大型，或 1大+2中，或 4中型
    """
    large  = [a for a in achievements if a['scale'] == '大型']
    medium = [a for a in achievements if a['scale'] == '中型']

    combos = [
        (len(large) >= 2,                      "已有大型项目 2 项 ✓"),
        (len(large) >= 1 and len(medium) >= 2, "已有大型 1 项 + 中型 2 项 ✓"),
        (len(medium) >= 4,                     "已有中型项目 4 项 ✓"),
    ]
    passed = any(ok for ok, _ in combos)
    reason = next((msg for ok, msg in combos if ok), None)

    if not passed:
        gap = f"当前：大型{len(large)}项、中型{len(medium)}项。" \
              f"需补充：{_high_gap(large, medium)}"
        return {"pass": False, "msg": gap}
    return {"pass": True, "msg": reason}

业绩录入界面的联动设计

用户操作系统响应
选择专业类别（下拉） 动态显示该专业对应的指标输入字段（如「房屋建筑」显示层数/高度/面积/合同额输入框）
填写任一指标数值 实时调用 judge_scale()，在表单右侧显示「🟢 大型」/「🟡 中型」/「🔴 小型」标签
保存业绩条目 将规模结果（scale 字段）一并存入数据库 achievements 表
点击「检查材料完整性」 读取所有业绩的 scale 字段，按职称级别调用对应 checker 函数，输出是否满足条件及缺口数量
⚠️ 注意：不同业绩类型（设计类、施工/监理类、造价类、咨询检测类）的规模要求数量不同。 系统需记录每条业绩的工作类型，分组统计后分别校验：
• 设计/施工/监理/项目管理：中级需 2中型以上；高级需 2大型 或 1大+2中 或 4中
• 咨询/检测/质量监督：中级需 5大中型(含1大型)；高级需 10大中型(含5大型)
• 工程造价/招投标：中级需 4中型以上 或 6小型；高级需 6大中型(含2大型) 或 10小型
