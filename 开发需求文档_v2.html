第一章系统定位与核心价值

1.1 背景

本系统面向建筑工程职称申报中介机构（广西），服务于职称评审申报全流程管理。操作人员为中介机构工作人员（单人或小团队），在本地单机运行 Flask Web 服务，通过浏览器访问。

客户（申报人）委托中介代办职称申报，中介需要收集客户材料、整理信息、在广西职称网完成在线填报，并跟踪审核结果。

1.2 核心设计原则

⚡ 最核心原则
系统的价值是「减少录入」，而不是「换个地方录入」。客户手中已持有大量原始证件材料，这些材料包含了申报所需约 70% 的信息。系统的职责是：从原始材料中自动提取 → 组织校验 → 辅助或自动完成在线填报。

❌ 错误方向（不能做）

  • 把广西职称网的所有字段搬到本地，要求人工逐个填写
  • 系统字段越多，录入工作量越大
  • 与直接在官网填写相比，工作量不减反增

✅ 正确方向（要做到）

  • 客户上传证件图片 → OCR自动提取字段
  • 人工只做"确认/纠正"，不做"录入"
  • 最终实现一键自动填写广西职称网

1.3 工作量对比

环节传统方式（中介手动）本系统目标节省比例
基本信息录入手动查看身份证逐字填写OCR自动提取，秒级完成~95%
学历职称信息手动查看各类证书填写OCR自动提取，人工确认~80%
社保信息手动数月份、计算总数OCR + 规则自动计算~90%
工程业绩手动整理多份材料填写OCR辅助提取 + 人工确认~50%
在线填报逐页手动填写（2-3小时/人）自动填报（15-30分钟/人）~85%
综合估算每位客户约 3-4 小时每位客户约 30-45 分钟~75%

1.4 使用场景

  1. 为新客户创建档案，根据其条件生成个性化材料清单
  2. 发送清单给客户，收集材料后存入本地目录
  3. 批量 OCR 处理客户证件，自动填入档案
  4. 资格预审，提前发现不满足条件的问题
  5. 辅助或自动完成广西职称网在线填报
  6. 跟踪申报进度、费用收款和最终结果

第二章核心业务流程

整个流程分为 10 个阶段，覆盖从政策解析到结果归档的完整生命周期。

0
政策文件解析（年度更新）
上传新一年申报通知文件（PDF/Word）→ AI 解析申报条件、材料要求、截止日期 → 自动更新材料清单模板和资格规则库。每年申报季开始前执行一次。
AI解析年度任务
1
创建申报人 + 智能生成材料清单
录入客户基本信息（姓名、现职称级别、学历、目标级别、申报批次）→ 系统根据政策规则生成个性化材料清单（专科比本科多2项、不同级别要求不同）。
规则引擎个性化清单
2
创建本地目录结构
在本地硬盘自动创建标准化目录（可配置根路径），用于存放客户所有原始材料文件。
/clients/2026/张三_高级工程师/
  ├── 00_资料清单.pdf
  ├── 01_身份证/
  ├── 02_学历证书/
  ├── 03_学位证书/
  ├── 04_职称证书/
  ├── 05_社保记录/
  ├── 06_在职证明/
  ├── 07_注册证书/
  ├── 08_工程业绩/
  ├── 09_论文著作/
  ├── 10_获奖证书/
  ├── 11_继续教育/
  └── 99_其他材料/
自动创建
3
向客户发送材料清单
导出两种格式：
• PDF打印版：含每项材料的具体要求（格式、时效、是否盖章等）
• 纯文字版：直接复制粘贴发送微信，方便客户查看
PDF导出文字版导出
4
材料收集跟踪（文件监听）
系统监控客户目录的文件变化（Python watchdog），自动识别哪些材料已收到、哪些还缺失，生成催收提醒。客户把文件发来后，中介保存到对应子目录即触发更新。
watchdog监听催收提醒
5
材料预检（质量验证）
• 图片清晰度检测（模糊自动提示重拍）
• 材料有效期校验：社保需近3个月内、在职证明需6个月内
• 完整性校验：身份证需正反面，缺一面提示
• 文件格式检查（支持 JPG/PNG/PDF）
质量检测有效期验证
6
OCR 批量处理 + 人工复核
按目录分类自动识别（身份证用腾讯云专用接口，其他用高精度通用接口）。输出置信度分数，低于阈值的字段标红。

人工复核界面：左侧显示原始图片，右侧显示识别出的字段，绿色=高置信度，黄色=需确认，红色=识别失败。点击确认即写入档案。
腾讯云OCR置信度评分左图右字段
7
资格预审（提前发现问题）
在正式提交前自动校验所有申报条件，生成预审报告：
✅ 资历年限：已满5年（5年3个月）— 达标
✅ 学历要求：本科 — 达标
❌ 社保月数：仅28个月，不足36个月 — 不达标
⚠️ 论文：1篇（建议至少2篇，否则竞争力弱）
⚠️ 继续教育：2024年度学时未录入
提前发现问题预审报告
8
准备填报数据
按广西职称网表单数据结构组织所有字段，生成填报预览页面（仿照官网样式展示最终内容），确认无误后进入自动填报。同时导出 JSON/Excel 备份，防止网站故障导致数据丢失。
填报预览JSON备份
9
网上自动填报
Playwright 驱动浏览器自动填写广西职称网，支持断点续传（记录每个模块的填报进度）。填报完成后截图存档，记录受理号。
填报进度记录：
{"basic_info":"done","education":"done",
 "work_exp":"done","achievements":"pending",
 "papers":"not_started","submit":"not_started"}
Playwright断点续传截图存档
10
后续跟踪与归档
记录提交时间、受理号。定期查询广西职称网审核状态，结果出来后记录通过/未通过，完整归档客户材料和系统数据。
进度查询结果归档

第五章模块功能设计

5.1 资料上传中心（核心新模块）

这是整个系统减负效果最显著的模块，是 Phase 3 的核心。

  • 申报人详情页内嵌"资料上传"标签页
  • 按证件类型分类上传（下拉选择文件类型）
  • 上传后立即触发对应类型的 OCR 识别
  • 人工复核界面：左侧显示原图，右侧展示识别字段
  • 字段状态：🟢 高置信度自动确认 · 🟡 低置信度待确认 · 🔴 识别失败需人工输入
  • 点击"确认导入"→ 字段写入对应数据库，无需重复填写

5.2 智能材料清单生成

  • 根据申报条件动态生成：现职称级别 + 目标级别 + 学历 → 不同清单
  • 每项材料附带具体要求说明（格式、时效、是否需盖章、复印件数量）
  • 导出格式：PDF（A4打印版）+ 纯文本（微信转发版）
  • 清单模板随政策文件年度更新

5.3 本地目录管理 + 文件监听

  • 系统设置中配置"客户材料根目录"（如 D:\职称材料）
  • 创建申报人时自动生成标准子目录结构
  • Python watchdog 监听目录变化：新文件进入时自动更新材料收集状态
  • 材料收集状态看板：绿色=已收 · 橙色=已催 · 红色=未收

5.4 资格预审引擎

  • 资历年限计算（从次月起算，已实现）
  • 社保月数自动验证（新增，与广西要求比对）
  • 学历+学位要求验证
  • 论文/获奖条件最低要求验证
  • 继续教育学时验证
  • 输出预审报告，颜色标注，可导出 PDF 发给客户确认

5.5 填报数据准备

  • 按广西职称网实际表单结构（经过页面分析）组织所有字段
  • 填报预览：仿照官网样式展示最终填报效果
  • 导出 JSON 备份（防止网站故障）
  • 字段映射配置化（官网表单变化时只需更新配置，无需改代码）

5.6 自动填报（Playwright）

  • Playwright Python 驱动 Chromium/Edge 浏览器
  • 分模块填报，每完成一个模块记录状态（断点续传）
  • 截图存档：每个关键步骤保存截图
  • 验证码处理策略：
    • 图形验证码 → 接入打码平台API（如超级鹰）
    • 短信验证码 → 弹窗提示中介手动输入，10分钟超时

5.7 进度看板（优化现有）

  • 申报人列表显示当前所处流程阶段（10阶段图标）
  • 批次管理：截止日期预警（已实现）
  • 费用收款状态跟踪
  • 工作台跟进提醒（已实现）
