第一章 系统定位与核心价值

1.1 背景

本系统面向建筑工程职称申报中介机构，服务于广西职称评审申报全流程管理。操作人员为中介机构工作人员（单人或小团队），在本地单机运行 Flask Web 服务。

1.2 核心设计原则

核心价值：系统的核心价值是"减少录入，而不是换个地方录入"。

客户（申报人）手中已经持有大量原始证件材料，这些材料包含了申报所需的绝大部分信息。系统的职责是：

  1. 从这些原始材料中自动提取信息（OCR）
  2. 组织和校验信息
  3. 辅助或自动完成广西职称网的在线填报
对比维度 传统方式 本系统目标
基本信息录入 手动查看身份证逐字填写 OCR 自动提取
学历职称信息 手动查看证书填写 OCR 自动提取
社保信息 手动计算月数填写 OCR + 规则自动计算
工程业绩 手动整理填写 辅助提取 + 人工确认
在线填报 逐页手动填写（2–3 小时/人） 自动填报（15–30 分钟/人）

1.3 使用场景

  • 中介人员新增一名申报客户
  • 向客户发送个性化材料清单
  • 客户提交材料后，批量 OCR 处理
  • 资格预审（提前发现问题）
  • 辅助或自动完成广西职称网填报
  • 跟踪申报进度和结果

第二章 核心业务流程

系统核心业务流程分为 11 个阶段（阶段 0 至阶段 10），以下为各阶段详细说明。

0
阶段 0：政策文件解析（年度更新）
  • 上传新一年申报通知文件（PDF/Word）
  • AI 解析申报条件、材料要求
  • 自动更新材料清单模板和资格规则库
↓
1
阶段 1：创建申报人 + 智能生成材料清单
  • 输入：客户现职称级别、学历、目标级别、申报批次
  • 系统根据政策规则生成个性化材料清单
  • 清单按人员情况动态调整（专科比本科多 2 项，不同级别要求不同）
↓
2
阶段 2：创建本地目录结构
  • 在本地硬盘自动创建标准化目录（详见下方目录树）
/clients/2026/张三_高级工程师/
  ├── 00_资料清单.pdf
  ├── 01_身份证/
  ├── 02_学历证书/
  ├── 03_学位证书/
  ├── 04_职称证书/
  ├── 05_社保记录/
  ├── 06_在职证明/
  ├── 07_注册证书/
  ├── 08_工程业绩/
  ├── 09_论文著作/
  ├── 10_获奖证书/
  ├── 11_继续教育/
  └── 99_其他材料/
↓
3
阶段 3：向客户发送材料清单
  • 生成 PDF 版（供打印）和文字版（供微信转发）
  • 清单包含：每项材料的具体要求（格式、时效、盖章要求等）
↓
4
阶段 4：材料收集跟踪（文件监听）
  • 系统监控客户目录的文件变化（Python watchdog）
  • 自动识别已收到的材料和缺失材料
  • 生成催收提醒
↓
5
阶段 5：材料预检
  • 图片清晰度检测（模糊自动提示重拍）
  • 材料有效期校验（社保需近 3 个月、在职证明需 6 个月内等）
  • 完整性校验（身份证需正反面等）
↓
6
阶段 6：OCR 批量处理 + 人工复核
  • 按目录分类自动识别（身份证用腾讯云专用接口，其他用通用 OCR）
  • 输出置信度分数，低于阈值标红
  • 人工复核界面：左侧原图、右侧字段、快速确认修改
↓
7
阶段 7：资格预审（提前发现问题）
  • 自动校验：资历年限、社保月数、学历要求、论文获奖要求
  • 生成预审报告，发现问题提前告知客户
↓
8
阶段 8：准备填报数据
  • 按广西职称网数据结构组织所有字段
  • 生成填报预览（仿照官网表单样式）
  • 导出 JSON/Excel 备份
↓
9
阶段 9：网上自动填报
  • Playwright 驱动浏览器自动填写广西职称网
  • 断点续传（记录每个模块的填报状态）
  • 填报完成截图存档，记录受理号
↓
10
阶段 10：后续跟踪
  • 记录提交时间、受理号
  • 定期查询审核状态
  • 记录最终结果，归档

3.2 工作经历表（work_experiences）— 新增

字段：id、applicant_id、start_date、end_date、work_unit、position（职务）、witness（证明人）

来源：劳动合同/在职证明 OCR

3.3 社保记录表（social_insurance）— 新增（关键）

字段：id、applicant_id、insure_location（参保地）、insure_start（起始年月）、insure_end（截止年月）、insure_months（月数，自动计算）、insure_unit（参保单位）

来源：社保记录打印件 OCR + 规则计算

注：广西要求近 3 年内连续参保，月数不足提前预警。

3.4 工程业绩表（achievements）— 扩展现有

新增字段：permit_no（施工许可证号）、completion_cert_no（竣工验收证号）

现有字段保留。

3.5 论文著作表（papers）— 保留现有

维持现有字段结构不变。

3.6 获奖情况表（awards）— 保留现有

维持现有字段结构不变。

3.7 继续教育表（edu_trainings）— 新增

字段：id、applicant_id、year（年度）、hours（学时）、institution（培训机构）、course_name（课程名称）

注：广西建工类要求每年不少于 90 学时。

3.8 执业资格证书表（pro_certificates）— 新增

字段：id、applicant_id、cert_type（证书类型，如注册建造师）、cert_no（证书编号）、reg_no（注册号）、valid_until（有效期）、specialty（专业）

3.9 材料文件表（materials）— 新增

字段：id、applicant_id、file_type（文件类型枚举）、file_path（本地路径）、ocr_status（待识别/已识别/已确认）、ocr_confidence（置信度 0–1）、ocr_result（JSON）、confirmed_at、created_at

3.10 批次表（batches）— 保留现有，扩展材料清单模板字段

保留现有字段结构，扩展新增材料清单模板配置字段。

第四章 原始材料与字段映射关系

以下列出各类原始材料可提取的字段、提取方式及注意事项。约 70% 字段可自动提取，30% 需人工确认或补充。

材料名称 可提取字段 提取方式 备注
身份证（正反面） 姓名、证号、性别、出生日期、民族、住址 腾讯云身份证 OCR 专用接口 正反面均需上传
毕业证书 学历、毕业院校、专业、毕业时间 通用 OCR + 规则解析 注意专科/本科区别
学位证书 学位、授予院校、授予日期 通用 OCR + 规则解析 无学位者跳过
现职称证书 职称等级、职称专业、证书编号、发证单位、发证日期 通用 OCR + 规则解析 多张证书取最高级
社保缴费记录单 参保地、参保起止月份、总月数、参保单位 OCR + 月数自动计算 广西人社局打印格式
在职证明/劳动合同 工作单位全称、现任职务、入职时间 通用 OCR + 规则解析 需加盖公章
注册证书（建造师等） 证书类型、证书编号、注册号、有效期 通用 OCR 注意有效期校验
获奖证书 奖项名称、颁奖单位、年份 通用 OCR 级别需人工核对
论文首页 题目、期刊名、发表时间、作者排名 通用 OCR 核心期刊需人工确认
工程业绩相关材料 工程名称、造价（部分） OCR 辅助，人工整合 需施工许可证 + 竣工验收
说明：约 70% 字段可自动提取，30% 需人工确认或补充。

第五章 模块功能设计

5.1 资料上传中心（新核心模块）

  • 按证件类型分类上传
  • 上传后立即触发 OCR 识别
  • 人工复核界面（左图右字段，快速确认）
  • 已确认字段写入对应数据库字段
  • 字段状态：🟢 已确认　🟡 待确认　🔴 识别失败

5.2 智能材料清单生成

  • 根据申报条件动态生成（级别 + 学历 → 不同清单）
  • 每项注明具体要求（格式、时效、是否需盖章）
  • 导出：PDF（打印版）+ 纯文本（微信发送版）

5.3 目录管理

  • 自动创建标准化本地目录结构
  • 文件监听：监控目录变化，实时更新材料收集状态
  • 目录路径配置（可自定义根目录）

5.4 资格预审引擎

  • 资历年限计算（从次月起算，政策规则）
  • 社保月数验证
  • 学历要求验证
  • 论文/获奖条件验证
  • 输出：预审报告（绿/黄/红三色标注）

5.5 填报数据准备

  • 按广西职称网表单结构映射所有字段
  • 填报预览页面
  • 数据导出备份（JSON 格式）

5.6 自动填报（Playwright）

  • 浏览器自动化填写广西职称网
  • 断点续传（分模块记录填报进度）
  • 截图存档
  • 验证码处理说明：图形码 → 打码 API；短信码 → 人工输入

5.7 进度看板（现有，优化）

  • 申报人列表 + 当前所处阶段
  • 批次管理 + 截止日期预警
  • 费用收款状态

第六章 技术架构

6.1 技术栈

组件 技术选型 说明
后端 Python 3.x + Flask 3.x Blueprint 架构
数据库 SQLite（WAL 模式） _migrate() 向后兼容
前端 Vanilla JS + 自定义 CSS 无框架依赖
OCR 腾讯云 OCR API v3 身份证专用接口 + 通用高精度接口
文件监听 Python watchdog 监控本地目录变化
自动填报 Playwright（Python） 支持断点续传
AI 解析 DeepSeek API OpenAI 兼容接口
Word 导出 python-docx 生成材料清单
Excel 导出 openpyxl 数据备份导出

6.2 运行环境

  • 本地单机运行（Windows / macOS / Linux）
  • Flask 开发服务器（非生产部署）
  • 浏览器访问 http://localhost:5000
